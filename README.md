Forecasts Grand Theft Auto VI's launch-day Twitch viewers hour by hour, from the first hour's print: a log-scale regression over past big launches, corrected with the game's own pre-release momentum and diurnal phase, with console-only calibration for this console-only launch. See BUILD.md for the method and the leave-one-out numbers.

## Run it
